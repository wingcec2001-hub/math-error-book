📝 第1題 — 單位圓兩點距離

三角函數距離公式中等
📋 題目
設 $A(\cos75°,\sin75°)$，點 $B(\cos15°,\sin15°)$，求 $A$、$B$ 兩點之距離。
來源：中女中、嘉中、延平、陽明高中 ｜ 兩點距離公式 餘弦差角公式 單位圓
掌握：已複習 0 次
✅ 正確答案
$AB = 1$
📖 詳細解析▼
💡 觀察
$A$、$B$ 都在單位圓上（$\cos^2\theta+\sin^2\theta=1$）。
列式 — 兩點距離公式
$$AB=\sqrt{(\cos75°-\cos15°)^2+(\sin75°-\sin15°)^2}$$
展開並利用 $\sin^2\theta+\cos^2\theta=1$
$$=\sqrt{1+1-2(\cos75°\cos15°+\sin75°\sin15°)}$$
套用餘弦差角公式
$$=\sqrt{2-2\cos(75°-15°)}=\sqrt{2-2\cos60°}$$
代入 $\cos60°=\frac{1}{2}$
$$=\sqrt{2-1}=\boxed{1}$$
🔑 核心公式▼
⭐ 單位圓兩點距離
$$PQ=\sqrt{2-2\cos(\theta_1-\theta_2)}$$
⚠️ 常見錯誤▼
#錯誤說明
1忘記差角公式硬算 $\cos75°-\cos15°$
2符號錯誤$(a-b)^2$ 展開時搞混
3角值記錯$\cos60°=\frac{1}{2}$ 非 $\frac{\sqrt3}{2}$
📚 類似練習題▼
練習 1-1
設 $P(\cos120°,\sin120°)$，$Q(\cos30°,\sin30°)$，求距離。
答案
$\sqrt{2}$
$$PQ=\sqrt{2-2\cos90°}=\sqrt{2}$$
練習 1-2
設 $M(\cos150°,\sin150°)$，$N(\cos30°,\sin30°)$，求距離。
答案
$\sqrt{3}$
$$MN=\sqrt{2-2\cos120°}=\sqrt{2+1}=\sqrt{3}$$

📝 第2題 — 平方相加法

三角函數平方相加法中等偏難
📋 題目
已知 $\sin\alpha+2\sin\beta=2$，$\cos\alpha+2\cos\beta=2$，則 $\cos(\alpha-\beta)=\;?$
來源：竹女、鳳中、南一中模考 ｜ 平方和技巧 餘弦差角公式
掌握：已複習 0 次
✅ 正確答案
$\cos(\alpha-\beta)=\dfrac{3}{4}$
📖 詳細解析▼
💡 關鍵
看到 $\sin$ 搭配 $\cos$ → 平方相加！
$$①\;\sin\alpha+2\sin\beta=2 \quad ②\;\cos\alpha+2\cos\beta=2$$
分別平方
$$①^2:\sin^2\alpha+4\sin\alpha\sin\beta+4\sin^2\beta=4$$
⚠️ 易錯！
交叉項 $=2\times1\times2=\mathbf{4}$，非 $2$！
$$②^2:\cos^2\alpha+4\cos\alpha\cos\beta+4\cos^2\beta=4$$
相加 + 化簡
$$1+4\cos(\alpha-\beta)+4=8 \implies 5+4\cos(\alpha-\beta)=8$$
解方程
$$\cos(\alpha-\beta)=\boxed{\frac{3}{4}}$$
🔑 核心公式▼
⭐ 平方相加通用公式
若 $\sin\alpha+k\sin\beta=m$，$\cos\alpha+k\cos\beta=n$：$$\cos(\alpha-\beta)=\frac{m^2+n^2-1-k^2}{2k}$$
📐 廣義版 ($a\neq1$)
若 $a\sin\alpha+b\sin\beta=m$，$a\cos\alpha+b\cos\beta=n$：$$\cos(\alpha-\beta)=\frac{m^2+n^2-a^2-b^2}{2ab}$$
⚠️ 常見錯誤▼
#錯誤說明
1交叉項係數$(a+2b)^2$ 交叉項為 $4ab$
2漏常數項忘記 $\sin^2+\cos^2=1$
3公式混淆$\cos(A-B)$ vs $\cos(A+B)$
📚 類似練習題▼
練習 2-1
已知 $\sin\alpha+2\sin\beta=1$，$\cos\alpha+2\cos\beta=\sqrt{2}$，求 $\cos(\alpha-\beta)$。
答案
$-\dfrac{1}{2}$
$$\cos(\alpha-\beta)=\frac{1+2-1-4}{4}=-\frac{1}{2}$$
練習 2-2（廣義）
已知 $3\sin\alpha+2\sin\beta=4$，$3\cos\alpha+2\cos\beta=2$，求 $\cos(\alpha-\beta)$。
答案
$\dfrac{7}{12}$
$$9+12\cos(\alpha-\beta)+4=20\implies\cos(\alpha-\beta)=\frac{7}{12}$$

📝 第3題 — 和角與差角比值求值

三角函數齊次式同除中等
📋 題目
已知 $\tan A = 2$，$\tan B = 3$，求 $\dfrac{\cos(A + B)}{\sin(A - B)}$ 的值。
來源：竹女、明道、嘉中、高附中 ｜ 和角公式 差角公式 齊次式同除
掌握：已複習 0 次
✅ 正確答案
$-5$
📖 詳細解析▼
💡 解題思維
已知條件為正切值 $\tan A$、$\tan B$，展開分子分母後為 $\sin,\cos$ 的二次齊次交叉式，分子分母同除以 $\cos A \cos B$ 即可全部轉為 $\tan$！
展開分子與分母
分子：$\cos(A + B) = \cos A \cos B - \sin A \sin B$
分母：$\sin(A - B) = \sin A \cos B - \cos A \sin B$
$$\frac{\cos(A + B)}{\sin(A - B)} = \frac{\cos A \cos B - \sin A \sin B}{\sin A \cos B - \cos A \sin B}$$
分子分母同除以 $\cos A \cos B$
$$= \frac{1 - \frac{\sin A \sin B}{\cos A \cos B}}{\frac{\sin A \cos B}{\cos A \cos B} - \frac{\cos A \sin B}{\cos A \cos B}} = \frac{1 - \tan A \tan B}{\tan A - \tan B}$$
代入 $\tan A = 2,\; \tan B = 3$
$$= \frac{1 - (2)(3)}{2 - 3} = \frac{1 - 6}{-1} = \frac{-5}{-1} = \boxed{-5}$$
🔑 核心公式▼
⭐ 齊次化正切轉化公式
$$\frac{\cos(A + B)}{\sin(A - B)} = \frac{1 - \tan A \tan B}{\tan A - \tan B}$$ $$\frac{\sin(A + B)}{\cos(A - B)} = \frac{\tan A + \tan B}{1 + \tan A \tan B}$$
⚠️ 常見錯誤▼
#錯誤說明
1餘弦和角正負號搞混$\cos(A+B) = \cos A\cos B \mathbf{-} \sin A\sin B$，易誤寫為 $+$
2正切差分母順序顛倒分母是 $\tan A - \tan B = 2 - 3 = -1$，易寫成 $3-2=1$ 導致差負號
📚 類似練習題▼
練習 3-1
已知 $\tan A = 4$，$\tan B = 2$，求 $\dfrac{\cos(A + B)}{\sin(A - B)}$ 之值。
答案
$-\dfrac{7}{2}$
$$=\frac{1 - \tan A\tan B}{\tan A - \tan B} = \frac{1 - 8}{4 - 2} = -\frac{7}{2}$$
練習 3-2
已知 $\tan A = 3$，$\tan B = \dfrac{1}{2}$，求 $\dfrac{\cos(A - B)}{\sin(A + B)}$ 之值。
答案
$\dfrac{5}{7}$
同除 $\cos A\cos B$ 得 $\dfrac{1 + \tan A\tan B}{\tan A + \tan B} = \dfrac{1 + 3/2}{3 + 1/2} = \dfrac{5/2}{7/2} = \dfrac{5}{7}$

📝 第4題 — 三角形內角與正切和

三角函數三角形恆等式困難
📋 題目
設 $A$、$B$、$C$ 為 $\triangle ABC$ 的三內角，且 $13\sin A = 17\cos B \cos C$，則 $\tan B + \tan C$ 爲多少？
(A) $\dfrac{13}{17}$　(B) $\dfrac{17}{13}$　(C) $1$　(D) $\dfrac{289}{169}$　(E) $\dfrac{169}{289}$
來源：南一中 ｜ 三角形內角和 和角公式 正弦展開
掌握：已複習 0 次
✅ 正確答案
(B) $\dfrac{17}{13}$
📖 詳細解析▼
💡 關鍵技巧
在 $\triangle ABC$ 中，$A + B + C = 180° \implies A = 180° - (B + C)$，所以 $\sin A = \sin(B + C)$！
角 $A$ 轉化為角 $B, C$ 的關係
因 $A = 180° - (B + C)$：
$$\sin A = \sin(180° - (B + C)) = \sin(B + C) = \sin B \cos C + \cos B \sin C$$
代入已知條件
已知 $13\sin A = 17\cos B \cos C$：
$$13(\sin B \cos C + \cos B \sin C) = 17\cos B \cos C$$
兩邊同除以 $13\cos B \cos C$
$$\frac{\sin B \cos C + \cos B \sin C}{\cos B \cos C} = \frac{17}{13}$$
左式拆開分配：
$$\frac{\sin B \cos C}{\cos B \cos C} + \frac{\cos B \sin C}{\cos B \cos C} = \frac{17}{13} \implies \tan B + \tan C = \boxed{\frac{17}{13}}$$
🔑 核心公式▼
⭐ 三角形內角恆等式
$$\tan B + \tan C = \frac{\sin(B + C)}{\cos B \cos C} = \frac{\sin A}{\cos B \cos C}$$
⚠️ 常見錯誤▼
#錯誤說明
1選成倒數 (A)$\tan B + \tan C = \frac{17}{13}$，容易看快選成 $\frac{13}{17}$
2不知道消角技巧沒利用 $A = 180°-(B+C)$ 將三變數減為兩變數
📚 類似練習題▼
練習 4-1
設 $A, B, C$ 為 $\triangle ABC$ 三內角，若 $5\sin A = 8\cos B \cos C$，求 $\tan B + \tan C$ 之值。
答案
$\dfrac{8}{5}$
$$\tan B + \tan C = \frac{\sin A}{\cos B\cos C} = \frac{8}{5}$$
練習 4-2
設 $A, B, C$ 為 $\triangle ABC$ 三內角，若 $7\sin A = 3\cos B \cos C$，求 $\tan B + \tan C$ 之值。
答案
$\dfrac{3}{7}$
$$\tan B + \tan C = \frac{\sin A}{\cos B\cos C} = \frac{3}{7}$$

📝 第5題 — 構造倍角求值

三角函數角變換與二倍角中等偏難
📋 題目
若 $135° < \theta < 180°$，且已知 $\cos(\theta + 45°) = -\dfrac{4}{5}$，求 $\sin(2\theta + 45°)$ 之值。
來源：附中 ｜ 角變換技巧 二倍角公式 象限正負
掌握：已複習 0 次
✅ 正確答案
$\dfrac{17\sqrt{2}}{50}$
📖 詳細解析▼
💡 巧思：令 $\phi = \theta + 45°$
所求 $2\theta + 45° = 2(\theta + 45°) - 45° = 2\phi - 45°$！
這樣就可以用 $\phi$ 的二倍角與和差角公式迅速解出！
判斷角度 $\phi$ 的範圍與求 $\sin\phi$
令 $\phi = \theta + 45°$。
因為 $135° < \theta < 180° \implies 180° < \phi < 225°$（$\phi$ 為第三象限角）。
已知 $\cos\phi = -\dfrac{4}{5}$，第三象限中 $\sin\phi < 0$：
$$\sin\phi = -\sqrt{1 - \left(-\frac{4}{5}\right)^2} = -\frac{3}{5}$$
計算 $2\phi$ 的正弦與餘弦值
$$\sin 2\phi = 2\sin\phi\cos\phi = 2\left(-\frac{3}{5}\right)\left(-\frac{4}{5}\right) = \frac{24}{25}$$
$$\cos 2\phi = 2\cos^2\phi - 1 = 2\left(\frac{16}{25}\right) - 1 = \frac{7}{25}$$
計算 $\sin(2\theta + 45°) = \sin(2\phi - 45°)$
套用差角公式 $\sin(A - B) = \sin A\cos B - \cos A\sin B$：
$$\sin(2\phi - 45°) = \sin 2\phi\cos 45° - \cos 2\phi\sin 45° = (\sin 2\phi - \cos 2\phi)\frac{\sqrt{2}}{2}$$
$$= \left(\frac{24}{25} - \frac{7}{25}\right)\frac{\sqrt{2}}{2} = \left(\frac{17}{25}\right)\frac{\sqrt{2}}{2} = \boxed{\frac{17\sqrt{2}}{50}}$$
🔑 核心公式▼
⭐ 角度構造技巧
$$2\theta + \alpha = 2(\theta + \alpha) - \alpha$$ $$\sin 2\phi = 2\sin\phi\cos\phi,\quad \cos 2\phi = 2\cos^2\phi - 1$$
⚠️ 常見錯誤▼
#錯誤說明
1象限正負號判斷錯誤$180° < \phi < 225°$ 是第三象限，$\sin\phi$ 為負值（$-3/5$ 而非 $+3/5$）
2硬解 $\theta$嘗試先求 $\theta$ 會非常繁瑣且容易算錯，應使用整體角度置換 $\phi=\theta+45°$
📚 類似練習題▼
練習 5-1
已知 $\cos(\theta + 45°) = \dfrac{3}{5}$ 且 $0° < \theta < 45°$，求 $\sin(2\theta + 45°)$。
答案
$\dfrac{31\sqrt{2}}{50}$
令 $\phi = \theta+45° \in (45°, 90°)$，$\sin\phi = 4/5$。$\sin 2\phi = 24/25, \cos 2\phi = -7/25$。$\sin(2\phi-45°) = \frac{24 - (-7)}{25}\frac{\sqrt{2}}{2} = \frac{31\sqrt{2}}{50}$。
練習 5-2
已知 $\cos(\theta + 45°) = \dfrac{5}{13}$ 且 $0° < \theta < 45°$，求 $\cos(2\theta + 45°)$。
答案
$\dfrac{119\sqrt{2}}{338}$
令 $\phi = \theta+45°$，$\sin\phi=12/13$。$\cos 2\phi = -119/169, \sin 2\phi = 120/169$。$\cos(2\phi-45°) = (\cos 2\phi + \sin 2\phi)\frac{\sqrt{2}}{2} = \frac{1\sqrt{2}}{338}$。

📝 第6題 — 正切倒數和與三角函數值

三角函數正切倒數關係中等偏難
📋 題目
已知 $0° < \theta < 45°$ 且 $\tan\theta + \dfrac{1}{\tan\theta} = \dfrac{5}{2}$，則：
(A) $\sin\theta\cos\theta = \dfrac{2}{5}$
(B) $\sin\theta + \cos\theta = \dfrac{3}{\sqrt{5}}$
(C) $\sin\theta - \cos\theta = \dfrac{1}{\sqrt{5}}$
(D) $\sin\theta = \dfrac{1}{\sqrt{5}}$
(E) $\sin\theta = \dfrac{2}{\sqrt{5}}$
來源：建中 ｜ 正切倒數關係 和差平方展開 角度範圍判斷
掌握：已複習 0 次
✅ 正確答案
(A)(B)(D)
📖 詳細解析▼
💡 核心轉換
$\tan\theta + \dfrac{1}{\tan\theta} = \dfrac{\sin\theta}{\cos\theta} + \dfrac{\cos\theta}{\sin\theta} = \dfrac{\sin^2\theta + \cos^2\theta}{\sin\theta\cos\theta} = \dfrac{1}{\sin\theta\cos\theta}$！
選項 (A) 分析：求 $\sin\theta\cos\theta$
由 $\tan\theta + \dfrac{1}{\tan\theta} = \dfrac{1}{\sin\theta\cos\theta} = \dfrac{5}{2}$，取倒數得：
$$\sin\theta\cos\theta = \frac{2}{5} \quad \implies \text{(A) 正確}$$
選項 (B) 分析：求 $\sin\theta + \cos\theta$
因為 $0° < \theta < 45°$，$\sin\theta > 0$ 且 $\cos\theta > 0$，故 $\sin\theta + \cos\theta > 0$。
$$(\sin\theta + \cos\theta)^2 = \sin^2\theta + 2\sin\theta\cos\theta + \cos^2\theta = 1 + 2\left(\frac{2}{5}\right) = 1 + \frac{4}{5} = \frac{9}{5}$$
開根號取正值：
$$\sin\theta + \cos\theta = \sqrt{\frac{9}{5}} = \frac{3}{\sqrt{5}} \quad \implies \text{(B) 正確}$$
選項 (C) 分析：求 $\sin\theta - \cos\theta$
計算平方值：
$$(\sin\theta - \cos\theta)^2 = 1 - 2\sin\theta\cos\theta = 1 - \frac{4}{5} = \frac{1}{5}$$
⚠️ 關鍵範圍判斷
當 $0° < \theta < 45°$ 時，$\sin\theta < \cos\theta$（正弦比餘弦小），所以 $\sin\theta - \cos\theta < 0$！
故開根號應取負號：
$$\sin\theta - \cos\theta = -\frac{1}{\sqrt{5}} \quad \implies \text{(C) 錯誤（選項漏負號）}$$
選項 (D)(E) 分析：求 $\sin\theta$
聯立 (B) 與 (C)：
$$\begin{cases} \sin\theta + \cos\theta = \dfrac{3}{\sqrt{5}} \\ \sin\theta - \cos\theta = -\dfrac{1}{\sqrt{5}} \end{cases}$$
兩式相加得 $2\sin\theta = \dfrac{2}{\sqrt{5}} \implies \sin\theta = \dfrac{1}{\sqrt{5}}$（故 $\cos\theta = \dfrac{2}{\sqrt{5}}$）。
$$\sin\theta = \frac{1}{\sqrt{5}} \quad \implies \text{(D) 正確，(E) 錯誤}$$
🔑 核心公式與速解▼
⭐ 正切倒數公式
$$\tan\theta + \frac{1}{\tan\theta} = \frac{1}{\sin\theta\cos\theta} = \frac{2}{\sin 2\theta}$$ $$(\sin\theta \pm \cos\theta)^2 = 1 \pm 2\sin\theta\cos\theta$$
⚡ 另解：直接解一元二次方程求 $\tan\theta$
令 $t = \tan\theta$，原式 $t + \frac{1}{t} = \frac{5}{2} \implies 2t^2 - 5t + 2 = 0 \implies (2t - 1)(t - 2) = 0$。
因 $0° < \theta < 45° \implies 0 < \tan\theta < 1$，故 $\tan\theta = \frac{1}{2}$。
由直角三角形（對邊 1，鄰邊 2，斜邊 $\sqrt{5}$）可得：$\sin\theta = \frac{1}{\sqrt{5}}, \cos\theta = \frac{2}{\sqrt{5}}$，各選項可瞬間秒殺！
⚠️ 常見錯誤▼
#錯誤說明
1差值開根號漏負號$0° < \theta < 45°$ 區間內 $\sin\theta < \cos\theta$，$\sin\theta - \cos\theta$ 必為負值，誤選 (C)
2正切解取錯根解 $2t^2-5t+2=0$ 得 $t=1/2$ 或 $2$，沒注意 $0°<\theta<45°$ 需取 $t<1$，誤將 $\sin\theta$ 算成 $2/\sqrt{5}$ 而選 (E)
📚 類似練習題▼
練習 6-1
已知 $0° < \theta < 45°$ 且 $\tan\theta + \dfrac{1}{\tan\theta} = \dfrac{10}{3}$，求 $\sin\theta$ 與 $\sin\theta - \cos\theta$ 之值。
答案
$\sin\theta = \dfrac{1}{\sqrt{10}},\; \sin\theta - \cos\theta = -\dfrac{2}{\sqrt{10}}$
由 $t + \frac{1}{t} = \frac{10}{3} \implies 3t^2 - 10t + 3 = 0 \implies (3t-1)(t-3)=0$。因 $0°<\theta<45°$，$\tan\theta = \frac{1}{3}$。得 $\sin\theta = \frac{1}{\sqrt{10}}, \cos\theta = \frac{3}{\sqrt{10}}$，故 $\sin\theta - \cos\theta = -\frac{2}{\sqrt{10}}$。
練習 6-2
已知 $45° < \theta < 90°$ 且 $\tan\theta + \dfrac{1}{\tan\theta} = \dfrac{25}{12}$，求 $\sin\theta - \cos\theta$ 之值。
答案
$\dfrac{1}{5}$
因 $45°<\theta<90°$，$\tan\theta > 1$。由 $12t^2-25t+12=0 \implies (3t-4)(4t-3)=0 \implies \tan\theta = \frac{4}{3}$。得 $\sin\theta = \frac{4}{5}, \cos\theta = \frac{3}{5}$。因為 $\theta > 45°$，$\sin\theta > \cos\theta$，故 $\sin\theta - \cos\theta = \frac{1}{5}$。

📝 第7題 — $\sin$、$\cos$ 連乘積經典題型

三角函數二倍角連乘中等
📋 題目
求下列各連乘式之值：
(1) $\cos 20° \cdot \cos 40° \cdot \cos 80° = \ ?$
(2) $\sin 10° \cdot \sin 30° \cdot \sin 50° \cdot \sin 70° = \ ?$
(3) $\cos 12° \cdot \cos 24° \cdot \cos 48° \cdot \cos 84° = \ ?$
來源：考型專論 ｜ 正弦二倍角 餘角轉換 補角約分
掌握：已複習 0 次
✅ 正確答案
(1) $\dfrac{1}{8}$　(2) $\dfrac{1}{16}$　(3) $\dfrac{1}{16}$
📖 詳細解析▼
💡 核心技巧：同乘最小角的 $\sin$ 產生骨牌二倍角
看到角度成等比數列的 $\cos$ 連乘，分子分母同乘 $2\sin(\text{最小角})$，連續利用 $2\sin\theta\cos\theta = \sin 2\theta$ 往上捲！
(1) 計算 $\cos 20°\cos 40°\cos 80°$
令 $P = \cos 20°\cos 40°\cos 80°$，同乘 $\sin 20°$：
$$P = \frac{\sin 20°\cos 20°\cos 40°\cos 80°}{\sin 20°} = \frac{\frac{1}{2}\sin 40°\cos 40°\cos 80°}{\sin 20°} = \frac{\frac{1}{4}\sin 80°\cos 80°}{\sin 20°} = \frac{\frac{1}{8}\sin 160°}{\sin 20°}$$
因 $\sin 160° = \sin(180° - 20°) = \sin 20°$，兩者約分得：
$$P = \frac{\frac{1}{8}\sin 20°}{\sin 20°} = \boxed{\frac{1}{8}}$$
(2) 計算 $\sin 10°\sin 30°\sin 50°\sin 70°$
先提出已知值 $\sin 30° = \frac{1}{2}$；其餘各項利用餘角公式 $\sin\theta = \cos(90°-\theta)$ 轉為餘弦：
$$\sin 70° = \cos 20°,\quad \sin 50° = \cos 40°,\quad \sin 10° = \cos 80°$$
原式化為：
$$\frac{1}{2} \cdot (\cos 20°\cos 40°\cos 80°) = \frac{1}{2} \times \frac{1}{8} = \boxed{\frac{1}{16}}$$
(3) 計算 $\cos 12°\cos 24°\cos 48°\cos 84°$
注意最後一項 $\cos 84°$：因為 $\cos 84° = \cos(180° - 96°) = -\cos 96°$（或 $\cos 84° = \sin 6°$），故原式可改寫為成等比的角：
$$-\cos 12°\cos 24°\cos 48°\cos 96°$$
同乘 $\sin 12°$ 連續二倍角：
$$= -\frac{\sin 12°\cos 12°\cos 24°\cos 48°\cos 96°}{\sin 12°} = -\frac{\frac{1}{16}\sin 192°}{\sin 12°}$$
因 $\sin 192° = \sin(180° + 12°) = -\sin 12°$，故：
$$= -\frac{\frac{1}{16}(-\sin 12°)}{\sin 12°} = \boxed{\frac{1}{16}}$$
🔑 核心公式與速算法▼
⭐ 餘弦連乘公式
若角度成 $2$ 倍遞增（$\theta, 2\theta, 4\theta, \dots, 2^{n-1}\theta$）： $$\prod_{k=0}^{n-1} \cos(2^k\theta) = \frac{\sin(2^n\theta)}{2^n\sin\theta}$$ 若最大角與最小角互補（如 $160°+20°=180°$），答案直接為 $\dfrac{1}{2^n}$！

2(3)小題補角符號漏負號$\cos 84° = -\cos 96°$ 與 $\sin 192° = -\sin 12°$ 兩次負號相消得正，易弄錯正負號

📝 第8題 — 根與係數關係與三角式化簡

三角函數根與係數中等
📋 題目
已知 $\sin\theta,\; \cos\theta$ 為方程式 $x^2 + px + q = 0$ 之二根，求 $2\cos^2\dfrac{\theta}{2} \left(\cos\dfrac{\theta}{2} + \sin\dfrac{\theta}{2}\right)^2$ 之值（以 $p, q$ 表示）。
來源：段考進階考型 ｜ 根與係數 半角降次公式 二倍角展開
掌握：已複習 0 次
✅ 正確答案
$1 - p + q$
📖 詳細解析▼
💡 解題思路
將半角 $\frac{\theta}{2}$ 的式子利用「降次公式」與「完全平方展開」還原為 $\theta$ 的形式，再代入根與係數關係！
列出根與係數關係
因 $\sin\theta, \cos\theta$ 為 $x^2 + px + q = 0$ 之二根：
$$\begin{cases} \sin\theta + \cos\theta = -p \\ \sin\theta\cos\theta = q \end{cases}$$
化簡所求式之第一部分：$2\cos^2\dfrac{\theta}{2}$
由餘弦二倍角/半角降次公式 $2\cos^2\frac{\theta}{2} = 1 + \cos\theta$。
化簡所求式之第二部分：$\left(\cos\dfrac{\theta}{2} + \sin\dfrac{\theta}{2}\right)^2$
展開平方：
$$\left(\cos\frac{\theta}{2} + \sin\frac{\theta}{2}\right)^2 = \cos^2\frac{\theta}{2} + 2\sin\frac{\theta}{2}\cos\frac{\theta}{2} + \sin^2\frac{\theta}{2} = 1 + \sin\theta$$
相乘展開並代入 $p, q$
原式相乘：
$$\text{原式} = (1 + \cos\theta)(1 + \sin\theta) = 1 + \sin\theta + \cos\theta + \sin\theta\cos\theta$$
代入根與係數：
$$= 1 + (\sin\theta + \cos\theta) + (\sin\theta\cos\theta) = 1 + (-p) + q = \boxed{1 - p + q}$$
🔑 核心公式▼
⭐ 半倍角轉化恆等式
$$2\cos^2\frac{\theta}{2} = 1 + \cos\theta,\quad 2\sin^2\frac{\theta}{2} = 1 - \cos\theta$$ $$\left(\cos\frac{\theta}{2} \pm \sin\frac{\theta}{2}\right)^2 = 1 \pm \sin\theta$$
⚠️ 常見錯誤▼
#錯誤說明
1根與係數兩根和漏負號兩根和為 $-\frac{b}{a} = -p$，誤記為 $+p$ 導致答案寫成 $1 + p + q$
2半角公式混淆未看出 $2\cos^2\frac{\theta}{2} = 1+\cos\theta$ 與 $(\cos\frac{\theta}{2}+\sin\frac{\theta}{2})^2 = 1+\sin\theta$ 的結構
📚 類似練習題▼
練習 8-1
已知 $\sin\theta,\; \cos\theta$ 為 $2x^2 - x - 1 = 0$ 之二根，求 $2\cos^2\dfrac{\theta}{2}\left(\cos\dfrac{\theta}{2} + \sin\dfrac{\theta}{2}\right)^2$ 之值。
答案
$1$
兩根和 $\sin\theta+\cos\theta = \frac{1}{2}$，兩根積 $\sin\theta\cos\theta = -\frac{1}{2}$。原式 $= 1 + (\sin\theta+\cos\theta) + \sin\theta\cos\theta = 1 + \frac{1}{2} - \frac{1}{2} = 1$。
練習 8-2
已知 $\sin\theta,\; \cos\theta$ 為 $x^2 + mx + n = 0$ 之二根，求 $2\sin^2\dfrac{\theta}{2}\left(\cos\dfrac{\theta}{2} - \sin\dfrac{\theta}{2}\right)^2$ 之值（以 $m, n$ 表示）。

$1 + m + n$ 或由展開得 $(1-\cos\theta)(1-\sin\theta) = 1 - (\sin\theta+\cos\theta) + \sin\theta\cos\theta = 1 - (-m) + n = 1 + m + n$
原式 $= (1-\cos\theta)(1-\sin\theta) = 1 - (\sin\theta+\cos\theta) + \sin\theta\cos\theta = 1 - (-m) + n = 1 + m + n$。

📝 第9題 — 網格三方向走捷徑與排容原理

排列組合走捷徑與排容困難
📋 題目
如圖，自 $A$ 到 $B$ 沿格子線走，規定只能走「$\uparrow$」、「$\rightarrow$」、「$\downarrow$」三個方向，且路徑不得重複走，則：
(1) $A$ 到 $B$ 有 $320$ 種走法；
(2) 不經過 $P$ 有 $\underline{\hspace{3em}}$ 種走法；
(3) 不經過 $Q$ 有 $\underline{\hspace{3em}}$ 種走法；
(4) 不經過 $P$ 且不經過 $Q$ 有 $\underline{\hspace{3em}}$ 種走法；
(5) 經過 $P$ 且經過 $Q$ 有 $\underline{\hspace{3em}}$ 種走法。
來源：南一中綠皮書 ｜ 直行轉折分析 排容原理 乘法原理
掌握：已複習 0 次

(2) 140　(3) 96　(4) 40　(5) 124
📖 詳細解析▼
💡 核心觀念：三向走法的乘法原理與排容
因為只能往「右、上、下」且不可重複，每一垂直行必須且只能通過一次（上下走動選定進出高度後向右跨行）。設全集 $n(U)=320$。
計算「過 $P$」與「過 $Q$」的走法數
經由分段乘法原理計算通過特定點的路徑數：
- 通過 $P$ 點的走法數 $n(P) = 320 - 140 = 180$
- 通過 $Q$ 點的走法數 $n(Q) = 320 - 96 = 224$
計算 (2)(3) 小題：不經過單點
- (2) 不過 $P$：$n(P') = n(U) - n(P) = 320 - 180 = \mathbf{140}$
- (3) 不過 $Q$：$n(Q') = n(U) - n(Q) = 320 - 224 = \mathbf{96}$
計算 (5) 小題：同時經過 $P$ 且經過 $Q$

$$= 320 - [180 + 224 - 124] = 320 - 280 = \mathbf{40}$$

📝 第10題 — 兩人進出門的限制計數問題

排列組合乘法原理中等
📋 題目
一百貨公司有五個門可供進出；甲、乙由不同門進入；且由不同門出來；且各人進去與出來之門不同；則其方法有 $\underline{\hspace{3em}}$ 種。
來源：南一中綠皮書 ｜ 乘法原理 限制條件 分步計數
掌握：已複習 0 次
✅ 正確答案
260 種
📖 詳細解析▼
💡 解題步驟拆解
先安排「進門」，再安排「出門」。注意甲、乙進出的交集情況！
步驟一：安排甲、乙「進門」
甲由 5 個門選 1 個進入（5 種），乙由剩下的 4 個門選 1 個進入（4 種）：
$$\text{進門方法數} = 5 \times 4 = 20 \text{ 種}$$
設甲進門為 $A$，乙進門為 $B$（門編號為 $A, B, C, D, E$）。
步驟二：安排甲、乙「出門」（分情況討論）
出門規則：甲不能從 $A$ 出，乙不能從 $B$ 出，且甲、乙出門不能相同。 討論甲出門的選擇： - 情況 1：甲從 $B$ 門出（即乙進的門）
此時甲有 1 種選法（選 $B$）。
乙不能選 $B$（自己進的），而甲選的是 $B$ 不影響乙選其他門，故乙可從 $A, C, D, E$ 中選 1 個出，有 $4$ 種選法。
情況 1 方法數 $= 1 \times 4 = 4$ 種。

- 情況 2：甲從非 $B$ 的其他門出（即 $C, D, E$）
甲有 3 種選法。
乙不能選 $B$（自己進的），也不能選甲選的門，故 5 個門扣掉 2 個，乙剩 $3$ 種選法。
情況 2 方法數 $= 3 \times 3 = 9$ 種。
步驟三：相乘得出總方法數
出門總方法數 $= 4 + 9 = 13$ 種。
總方法數：
$$\text{總方法數} = 20 \times 13 = \boxed{260} \text{ 種}$$
🔑 核心公式與模型▼
⭐ $n$ 個門兩人進出模型通用公式
若有 $n$ 個門，甲乙不同門進、不同門出，且每人不原門出： $$\text{方法數} = P^n_2 \times [(n-1) + (n-2)^2] = n(n-1) \cdot (n^2 - 3n + 3)$$ 當 $n=5$ 時：$5 \times 4 \times (25 - 15 + 3) = 20 \times 13 = 260$。
⚠️ 常見錯誤▼
#錯誤說明
1出門直接乘 $4 \times 3$誤以為甲剩 4 個、乙剩 3 個直接相乘得 12，忽略了「甲若選乙進的門，乙反而有 4 種選擇」的情況
2未分類討論甲出門是否佔用乙的原進門會影響乙的可選數，必須分類討論

練習 10-1
某展覽館有 4 個門供進出，甲、乙兩人由不同門進，不同門出，且各自不從原門出，求方法數。

84 種

📝 第11題 — 等比級數求和與誤差不等式

數列與級數等比級數與不等式中等
📋 題目
$n$ 為正整數且 $S_n = 1 + \dfrac{1}{2} + \dfrac{1}{4} + \dfrac{1}{8} + \dots + \dfrac{1}{2^{n-1}}$，若 $2 - S_n < 0.001$，求 $n$ 之最小值。
來源：南一中綠皮書 ｜ 等比級數和 指數不等式 項數判定
掌握：已複習 0 次
✅ 正確答案
$n = 11$
📖 詳細解析▼
💡 關鍵技巧
首項 $a_1=1$，公比 $r=\frac{1}{2}$，共有 $n$ 項。套用等比級數公式求出 $S_n$ 後代入化簡。
計算等比級數和 $S_n$
$$S_n = \frac{a_1(1 - r^n)}{1 - r} = \frac{1 \cdot \left(1 - \left(\frac{1}{2}\right)^n\right)}{1 - \frac{1}{2}} = 2\left(1 - \frac{1}{2^n}\right) = 2 - \frac{1}{2^{n-1}}$$
化簡條件式 $2 - S_n < 0.001$
將 $S_n$ 代入：
$$2 - S_n = 2 - \left(2 - \frac{1}{2^{n-1}}\right) = \frac{1}{2^{n-1}}$$
不等式要求：
$$\frac{1}{2^{n-1}} < 0.001 = \frac{1}{1000} \iff 2^{n-1} > 1000$$
求最小正整數 $n$
已知 2 的次方數： - $2^9 = 512 < 1000$ - $2^{10} = 1024 > 1000$ 故 $n - 1 \ge 10 \implies n \ge 11$。
最小正整數 $n = \boxed{11}$。
🔑 核心公式▼
⭐ 等比級數求和公式
$$S_n = \frac{a_1(1 - r^n)}{1 - r}$$ 常記：$2^{10} = 1024$
⚠️ 常見錯誤▼
#錯誤說明
1項數誤判為 $n-1$ 項$1, 1/2, \dots, 1/2^{n-1}$ 共有 $n$ 項，展開化簡後為 $\frac{1}{2^{n-1}}$
2次方判斷少算 1$2^{n-1}>1000 \implies n-1\ge 10 \implies n\ge 11$，容易誤寫為 $n=10$
📚 類似練習題▼
練習 11-1
設 $S_n = 1 + \frac{1}{3} + \frac{1}{9} + \dots + \frac{1}{3^{n-1}}$，若 $\frac{3}{2} - S_n < 0.005$，求正整數 $n$ 之最小值。
答案
$n = 6$
$S_n = \frac{3}{2}(1 - (1/3)^n) \implies \frac{3}{2} - S_n = \frac{1}{2 \cdot 3^{n-1}} < \frac{1}{200} \implies 3^{n-1} > 100$。因 $3^4=81, 3^5=243$，故 $n-1 \ge 5 \implies n \ge 6$。
練習 11-2
設 $S_n = 1 + \frac{1}{2} + \dots + \frac{1}{2^{n-1}}$，若 $2 - S_n < 10^{-4}$，求最小正整數 $n$。
答案
$n = 15$
$\frac{1}{2^{n-1}} < \frac{1}{10000} \implies 2^{n-1} > 10000$。因 $2^{13}=8192, 2^{14}=16384$，故 $n-1 \ge 14 \implies n=15$。

📝 第12題 — 加權級數和與通項求值

數列與級數前n項和求通項中等偏難
📋 題目
若一數列 $\langle a_n \rangle$ 滿足 $a_1 + 2a_2 + 3a_3 + \dots + n a_n = n^2(n + 1)$，求：
(1) $a_n = \ ?$（以 $n$ 表示）
(2) $a_{200} = \ ?$
來源：南一中綠皮書 ｜ 累加和差分 因式化簡 一般項求解
掌握：已複習 0 次
✅ 正確答案
(1) $a_n = 3n - 1$　(2) $a_{200} = 599$
📖 詳細解析▼
💡 核心技巧：$S_n - S_{n-1}$ 差分法
令 $T_n = a_1 + 2a_2 + \dots + n a_n = n^2(n+1)$，則 $T_n - T_{n-1} = n a_n$！
當 $n = 1$ 時
$$1 \cdot a_1 = 1^2(1 + 1) = 2 \implies a_1 = 2$$
當 $n \ge 2$ 時，利用 $T_n - T_{n-1}$
$$n a_n = T_n - T_{n-1} = n^2(n + 1) - (n - 1)^2 n$$
提出公因式 $n$：
$$n a_n = n [n(n + 1) - (n - 1)^2]$$
兩邊同除以 $n$（因 $n \ge 2 \neq 0$）：
$$a_n = (n^2 + n) - (n^2 - 2n + 1) = 3n - 1$$
驗證 $n = 1$ 與求 $a_{200}$
將 $n = 1$ 代入 $a_n = 3(1) - 1 = 2 = a_1$，完全符合！
故對所有正整數 $n$，通項為：
$$a_n = \boxed{3n - 1}$$
代入 $n = 200$：
$$a_{200} = 3(200) - 1 = 600 - 1 = \boxed{599}$$
🔑 核心公式▼
⭐ 級數差分得通項
若 $T_n = \sum_{k=1}^n b_k$，則 $b_n = T_n - T_{n-1}\;(n \ge 2)$
⚠️ 常見錯誤▼
#錯誤說明
1忘記左邊是 $n a_n$差分出來的是第 $n$ 項 $n a_n$，忘記同除以 $n$
2未檢驗 $n=1$使用 $T_n - T_{n-1}$ 務必回頭檢驗首項 $a_1$ 是否滿足通式
📚 類似練習題▼
練習 12-1
若 $a_1 + 2a_2 + \dots + na_n = n(n+1)(n+2)$，求 $a_n$ 與 $a_{50}$。
答案
$a_n = 3n + 3,\; a_{50} = 153$
$na_n = n(n+1)(n+2) - (n-1)n(n+1) = n(n+1)[(n+2)-(n-1)] = 3n(n+1) \implies a_n = 3n+3$。$a_{50} = 153$。
練習 12-2
若 $a_1 + 2a_2 + \dots + na_n = n^3$，求 $a_n$。
答案
$a_n = 3n - 3 + \dfrac{1}{n}\;(n \ge 2)$，$a_1 = 1$
$na_n = n^3 - (n-1)^3 = 3n^2 - 3n + 1 \implies a_n = 3n - 3 + \frac{1}{n}$。

📝 第13題 — 等差數列「項之比」與「和之比」轉換

數列與級數等差項比與和比中等
📋 題目

💡 關鍵絕招：等差中項 $S_{2k-1} = (2k-1) \cdot a_k$
等差數列前 $2k-1$ 項之和等於「項數 $\times$ 第 $k$ 項（等差中項）」！
因此：前 $2k-1$ 項和的比 $=$ 第 $k$ 項之比！
(1) 已知「第 $n$ 項比」，求「前 9 項和之比」
前 $9$ 項和之比等於第 $\frac{9+1}{2} = 5$ 項（即 $a_5$）之比：
$$\frac{S_9}{S'_9} = \frac{9a_5}{9a'_5} = \frac{a_5}{a'_5}$$
將 $n = 5$ 代入第 $n$ 項比 $(2n+3) : (3n+2)$：
$$\frac{S_9}{S'_9} = \frac{2(5) + 3}{3(5) + 2} = \frac{10 + 3}{15 + 2} = \boxed{\frac{13}{17}} \quad (13 : 17)$$
(2) 已知「前 $n$ 項和比」，求「第 10 項之比」
第 $10$ 項（$a_{10}$）是前 $2(10) - 1 = 19$ 項的等差中項：
$$\frac{a_{10}}{a'_{10}} = \frac{19a_{10}}{19a'_{10}} = \frac{S_{19}}{S'_{19}}$$
將 $n = 19$ 代入前 $n$ 項和比 $(2n+1) : (n+3)$：
$$\frac{a_{10}}{a'_{10}} = \frac{2(19) + 1}{19 + 3} = \frac{38 + 1}{22} = \boxed{\frac{39}{22}} \quad (39 : 22)$$
🔑 核心公式速查▼
⭐ 等差項比與和比互換法則
1. 給 $a_n : a'_n$，求 $S_m : S'_m$ $\implies$ 代入 $n = \dfrac{m+1}{2}$
2. 給 $S_n : S'_n$，求 $a_k : a'_k$ $\implies$ 代入 $n = 2k - 1$
⚠️ 常見錯誤▼
#錯誤說明
1(2)小題直接代 $n=10$前 $n$ 項和公式是二次式，求第 10 項比不可直接代 $n=10$，應代中項項數 $n=2(10)-1=19$
2互換關係記反牢記「求和代中項，求項代兩倍減一」
📚 類似練習題▼
練習 13-1
兩等差數列第 $n$ 項比為 $(3n-1) : (2n+5)$，求前 $11$ 項和之比。
答案
$17 : 17 = 1 : 1$
前 11 項中項為第 6 項，代 $n=6 \implies (18-1):(12+5) = 17:17 = 1:1$。
練習 13-2

答案
$4 : 3$
第 11 項對應前 $2(11)-1 = 21$ 項和，代 $n=21 \implies \frac{7(21)+1}{4(21)+27} = \frac{148}{111} = \frac{4}{3}$。

📱 手機存取方式

以下方法讓你在學校用手機也能開啟錯題本：

📂 方法一：OneDrive 同步 最簡單
  1. 將 D:\數學錯題本\ 資料夾搬到 OneDrive 目錄中
  2. 手機安裝 OneDrive App，登入同一帳號
  3. 開啟 HTML 檔案 → 選擇「在瀏覽器中開啟」
  4. 可加到手機主畫面方便存取
🌐 方法二：GitHub Pages 免費架站 推薦
  1. 註冊 GitHub 帳號，建立新 Repository
  2. 上傳 HTML 檔案（改名為 index.html）
  3. Settings → Pages → Source 選 main branch
  4. 取得網址 https://你的帳號.github.io/倉庫名/
  5. 手機瀏覽器開啟即可，隨時隨地複習！
⚡ 方法三：Netlify 拖曳部署
  1. 進入 app.netlify.com/drop
  2. 直接拖曳 HTML 檔案到頁面上
  3. 自動取得免費網址，手機開啟即可
